# 📚 Bookstore Sales Analysis using SQL

## 📌 Project Overview
This project analyzes bookstore sales data using SQL to extract
insights related to revenue, customer behavior, and inventory.

## 🛠 Tools Used
- PostgreSQL
- SQL
- CSV files

## 🗄 Database
- PostgreSQL was used for schema design, data loading, and analysis.

## 📊 Key Analysis
- Total revenue generated
- Best-selling books & genres
- Top customers by spending
- Remaining stock after orders

## 📂 Dataset
- Books.csv
- Customers.csv
- Orders.csv
